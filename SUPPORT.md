# Support

Maverick v3 is experimental.

## Community Support

Until public support channels are configured, use GitHub issues after the repository is public for:

- reproducible bugs
- documentation gaps
- setup failures
- feature requests

Do not use public issues for vulnerabilities; follow `SECURITY.md`.

## What Maintainers Support

Maintainers prioritize:

- clean-clone setup failures
- workspace isolation bugs
- app contract correctness
- reproducible runtime failures
- security hardening work
- documentation that helps contributors become productive

## What Maintainers Do Not Support Yet

- production deployments with sensitive data
- internet-exposed deployments
- private forks with local modifications
- v2 compatibility
- undocumented app internals
- recovery of deleted local workspace data

## Commercial Support

No commercial support channel is defined in this repository.
