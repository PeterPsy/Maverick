Maverick Browser

Your agent starts here.

Connect this tab and ask Maverick what to browse or change.

  1. Open Companion

    Click Maverick Browser Companion in Chrome’s extension toolbar on this tab.

  2. Connect agent tab

    Allow access if Chrome asks. Maverick opens in your existing Chrome tab and connects automatically after sign-in.

Your agent browses HTTPS websites, clicks, fills fields, chooses options and uses the keyboard. It can read pages and analyze images, video and audio.

Keep this tab open. After connecting, you can close the Maverick setup tab and continue from the macOS app. Sign-in and file selection stay in Chrome. Disconnect in Companion to stop the agent’s access.
