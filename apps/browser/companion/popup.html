How sharing works

Choose Open agent tab, then open Companion in Chrome’s toolbar on that tab and connect once. Allow access if Chrome asks. Sign in to Loopino if needed; your agent tab connects automatically.

The agent can browse HTTPS websites, click, fill fields, choose options and use the keyboard. It can submit forms and change your account when you request it.

Chrome asks for website access and browser control. Only your connected agent tab is operated. Sign-in and file selection stay in Chrome.

Companion looks for Loopino in this Chrome profile. Desktop apps and other profiles use a tab here for initial authorization. Once connected, you can close that Loopino tab and continue from the macOS app.
